How end of support is determined

Microsoft supports each Azure Local release for six months. The end of support date shown here is 180 days after the release first became available, as listed on Microsoft's release information. Releases ending within 60 days are flagged as ending soon.

This only covers generic Azure Local releases. Verify supported installation and update paths with your OEM hardware vendor. Data is refreshed daily.
