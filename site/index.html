How this works

Microsoft supports each Azure Local release for six months. The end of support date is 180 days after a release first became available, as listed in Microsoft's release information. Releases within 60 days of that date are marked ending soon.

Only generic Azure Local releases are covered. Check supported installation and update paths with your OEM hardware vendor.

Get the dates in your calendar: subscribe by URL (not import, so it stays up to date) to calendar.ics, or to calendar-reminders.ics for a reminder 30 and 7 days before each end of support. Works in Outlook, Apple Calendar and Google Calendar (which ignores reminders from subscribed calendars).
