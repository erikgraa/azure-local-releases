How end of support is determined

Microsoft supports each Azure Local release for six months. The end of support date shown here is 180 days after a release first became available, as listed in Microsoft's release information. Releases within 60 days of that date are flagged as ending soon. The release recommended for new deployments is the one Microsoft names on that page.

This only covers generic Azure Local releases. Verify supported installation and update paths with your OEM hardware vendor.
